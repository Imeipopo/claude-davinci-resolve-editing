# 片頭提示詞模板

> 這份是本 repo 自己改寫的模板（MIT），寫法參考了 [Skillry](https://skillry.dev/ai-videos/opus-5-5) 收錄的公開提示詞；每個模板的「參考原片」連到原作者的影片。實作與實測見 [第 20 章](../docs/zh-TW/20-intro-generator.md)。

## 怎麼用

1. 先從「風格模板」挑一個，把它的「填空欄」換成自己的內容（標題、配色、字體等）。
2. 再填「共通區塊」的幾個欄位（秒數、比例、配樂方式等），整段接在風格模板的提示詞後面，一起丟給 Claude。
3. 佔位符一律寫成 `{{欄位名}}`，丟出去之前搜尋一次 `{{`，確定沒有漏填。
4. 模板裡的分鏡秒數是以「建議長度」寫的；改了 `{{秒數}}` 就請 Claude 按比例縮放，但收尾鎖定的停留時間不縮。
5. 想做隨機片頭庫，看最後一節「隨機組合建議」，把可以抽換的欄位做成池子。

## 共通區塊（每個模板後面都接這段）

要填的欄位：

| 欄位 | 範例值 | 說明 |
|---|---|---|
| `{{工具}}` | Remotion | Remotion／HyperFrames／單檔 HTML 三選一 |
| `{{秒數}}` | 6.00 | 寫到小數點後兩位 |
| `{{比例}}` | 16:9 | 16:9／9:16／1:1，可寫多個，例如「16:9 與 9:16」 |
| `{{收尾方式}}` | 停住 | 停住／循環／擦出接正片 |
| `{{配樂方式}}` | A | A 程式合成配樂／B 只放 UI 音效／C 不放聲音 |
| `{{BPM}}` | 120 | 120 BPM 一拍 0.5 秒、一小節 2 秒 |
| `{{工作方式}}` | 先確認 | 先確認（先給分鏡表和靜態圖）／一次做完 |

```
【共通規格與規則】

一、規格
- 長度：剛好 {{秒數}} 秒，不多不少，用 ffprobe 驗證。
- 比例與解析度：{{比例}}。16:9 輸出 1920x1080；9:16 輸出 1080x1920；1:1 輸出 1080x1080。要多種比例時，用同一套時間軸、同一個 draw(t)，各比例只改版面配置，平行輸出，不要分開各做一支。
- 60fps，總格數 = 秒數 × 60。
- 收尾方式：{{收尾方式}}。
  - 停住：最後一個鎖定畫面（標題或 Logo）要在片尾前完整出現，並停留至少「max(1.5 秒, 畫面字數 ÷ 5 + 0.8 秒)」；10 秒以上的片頭停 2.5～3 秒。停留期間只允許極輕微的呼吸縮放 1.000→1.012→1.000，其他東西都不准動。
  - 循環：最後一格的下一格必須等於第一格，位置、透明度、旋轉、游標位置和速度全部回到開頭。只輸出 [0, 秒數) 的格數，不要重複最後一格。輸出後比對第一格和最後一格的差異，確認接得起來。
  - 擦出接正片：照「停住」的規則停留後，最後 0.4 秒用本片同一種轉場手法退場到純底色，方便剪接接正片。
- 安全區：
  - 16:9：重要文字放在中央 90% 範圍內；如果之後可能裁成直式，標題和 Logo 要落在中央寬 608px 的 9:16 區域內。
  - 9:16（IG Reel、Shorts）：上方 250px、下方 500px、右側 200px 會被介面蓋住，不放任何重要文字；部分手機會把左右各裁掉約 100px，重要文字再往內縮。
  - 1:1：四邊各留 5%。

二、實作規則（{{工具}}）
- 畫面必須是時間的純函數：給同一個 t，永遠畫出同一個畫面；任意順序跳格都一樣。
  - Remotion：t = useCurrentFrame() / fps，所有樣式由 t 算出；不用 useState、useEffect 做動畫。
  - HyperFrames：所有動畫掛在暫停的時間軸上，由框架逐格 seek；不用 requestAnimationFrame、setTimeout 或自動播放的動畫。
  - 單檔 HTML：提供 async window.seek(t) 或 draw(t)，在裡面算出所有樣式。
- 禁止 CSS transition、CSS animation、setInterval、setTimeout、跨影格累積的狀態（包括累積式物理模擬）。粒子、彈跳、物理都要寫成 t 的解析式。
- 所有隨機值用固定種子的亂數產生器（例如 mulberry32），種子寫在設定檔裡。
- 彈簧用閉式解（阻尼振盪的步階響應），阻尼比 0.75～0.85、頻率 2～3 Hz，過衝不超過 5%，約 0.3 秒內收斂。同一個值多次換目標時，寫成「每次換目標疊一個彈簧」的總和，保持是 t 的純函數。不用彈跳到停不下來的卡通緩動。
- 動態模糊用子影格：每一格在前後各 1/240 秒內取 4～6 個子影格平均混合（約 180 度快門）。靜止的文字必須保持銳利。Remotion 可用 @remotion/motion-blur 的 CameraMotionBlur（samples 5、shutterAngle 180）。
- 輸出流程：逐格擷取（Remotion 用內建 render；HyperFrames 用它的 render；單檔 HTML 用 Playwright 無頭 Chromium 逐格截圖），再用 ffmpeg 編碼：H.264、yuv420p、CRF 16、preset slow、BT.709 色彩標記、-movflags +faststart；有聲音時 AAC 320k、48kHz。
- 字型：所有字型在第一格之前就要載入完成（document.fonts.ready 或 Remotion 的 delayRender），否則前幾格會是備援字型。算繪完逐張確認字型正確、沒有豆腐方塊。
- 不要用 will-change 在會被鏡頭縮放的元素上，否則文字會糊。暗色大面積漸層加 1～2% 的雜訊抖色，避免 H.264 壓出色階斷層。1080p 下線條至少 2px，避免慢速移動時閃爍。
- 所有可調整的東西（文字、色票、字體、秒數、BPM、強度、種子）集中放在最上面一個 config 物件裡。

三、中文排版
- 文字一字不改照我給的內容，不要自己加標語、翻譯副標、標點或語助詞。
- 大標不加句號。斷行依詞斷，不可以把一個詞拆成兩行，也不能留下單獨一個字的孤字行；行首不放逗號、句號等標點。
- 中文大標字距用 0 到 +20（千分之一 em），不要套用英文常見的 −40 到 −80，中文會黏在一起。英文大寫標籤字距 +80～+120。
- 最小字高：16:9 與 1:1 不小於畫面高度 2.2%；9:16 不小於 48px。
- 文字對背景的對比至少 4.5:1，大標至少 3:1。
- 舊文字要先離開，新文字才進入同一個位置；在變形容器裡換文字時，文字要有自己的進出場時間和遮罩，不能和下一段重疊。
- 每段文字停留時間至少「字數 ÷ 5 + 0.6 秒」，讓人讀得完。

四、配樂：{{配樂方式}}，{{BPM}} BPM
- 時間格線：第一拍在 t = 0.000 秒，一拍 = 60 ÷ {{BPM}} 秒，四拍一小節。分鏡上的重點事件（標題落下、轉場、Logo 出現）都要落在拍點上，鎖定畫面落在某一小節的第一拍。前 8 拍每一拍都要有事發生，之後至少每兩拍一件事。
- A 程式合成配樂：全部用程式合成（numpy 或 Web Audio 離線算繪），不用取樣、音檔、VST。要有乾淨的節拍、溫暖的低音、克制的旋律，鎖定那一拍給一個明確的收束（和弦解決或重拍），之後讓殘響自然收掉，最後 0.3 秒淡出避免爆音。轉場音效比音樂小 6～10 dB。
- B 只放 UI 音效：每個事件一個程式合成的短音效（咻聲、點擊、低頻重擊、清脆鈴聲）。音效用「實測波峰」對齊事件時間，不是用檔案起點對齊。
- C 不放聲音：輸出無音軌的 MP4，但畫面仍照 {{BPM}} 的拍點排，並交一份拍點時間表，方便我後製配樂。
- A 和 B 都要混音：用 ffmpeg loudnorm 正規化到整合響度 −14 LUFS、真峰值 ≤ −1 dBTP，交付前用 ebur128 量一次並回報數值。

五、禁用清單（除非風格模板明確要求，否則一律不要）
大腦、機器人、電路板、神經網路圖、閃亮星星、霓虹紫藍漸層、玻璃擬態、粒子爆炸、鏡頭光暈、隨機漂浮的光點或泡泡、鏡頭隨機飄移或晃動、彈跳卡通緩動、UI 元件上的漸層、拿全畫面交叉淡化當萬用轉場、角落浮水印、進度條、頁碼、裝飾外框、假科技 HUD、像簡報模板或 Canva 的版面、emoji、圖片裡的 AI 生成文字、任何真實品牌或名人。
風格模板的規則和這裡衝突時，以風格模板為準。

六、自我檢查
1. 寫程式前，先列出分鏡表：每一段的起訖秒數、對應拍號、畫面內容、文字、進出場手法。
2. 正式算繪前，在每個重點時刻（至少 8 張，含開場第一格、每次換字、鎖定完成那一格、最後一格）輸出靜態圖，用 ffmpeg tile 拼成一張 contact sheet，逐張檢查：字擠不擠、有沒有孤字或拆詞、對比夠不夠、有沒有過曝成一片白、主體有沒有被光效或文字擋住、有沒有超出安全區、字型是不是指定的那套。有問題先修再算繪。
3. 算繪後再檢查：總長度與格數、第一拍是否在 0 秒、相鄰格差異是否有單格突跳（差異大於前後格 3 倍）、循環接縫、響度數值。
4. 工作方式：{{工作方式}}。若是「先確認」，就先給我分鏡表、拍點表和 4 張關鍵靜態圖，等我說可以再寫完整影片；若是「一次做完」，就自己做完上面三步再交。

七、交付
- 每個比例一支 MP4，檔名用「模板名_比例_秒數.mp4」。
- 完整原始碼，附一行就能重新算繪的指令。
- 回報：每一段的實際起訖秒數、拍點表、用了哪些字型（名稱與來源）、響度實測值，以及 config 裡哪些參數可以調整強度、改了會怎樣。
```

## 隨機組合建議

### 怎麼把模板變成隨機片頭庫

1. 每個模板分成兩種欄位：
   - 固定欄位：頻道名、標題、名字、標語、衛教內容。這些一次填好就不動。
   - 隨機池欄位：色票組、字體組、BPM、轉場手法、收尾方式、子選項、步進速度。
2. 用一個種子決定每一池抽哪一個（例如種子 1～50），把抽到的結果寫進共通區塊的 config，跟著原始碼一起存，之後要重做同一支只要給同一個種子。
3. 一次抽 6～10 組，先只算繪每組的鎖定畫面一張靜態圖，拼成 contact sheet 挑順眼的，再算繪完整影片。這樣比整支都算完再挑省很多時間。
4. 「不要搭在一起」的清單寫成程式規則，抽到衝突組合就重抽。

### 不要搭在一起的組合

- 模板 2（高級極簡）配上故障、粒子、套印錯位或 P1、P7 這類螢光色票：高級感會立刻消失。
- 模板 7C（故障卡點）用在婚禮或衛教：閃爍和撕裂不適合，也有光敏風險；衛教一律不要用 C。
- 模板 6（字體即結構）配 120 BPM 以上的卡點配樂：它是照語句停頓排時間的，硬套快節拍會讓字來不及讀。配樂請選 A 的慢版（90～100 BPM）或 C。
- 模板 11（像素風）配襯線或楷書字體（F3、F4、F5）：細筆畫在低解析度會斷掉。
- 模板 8（手作）配完美向量漸層、玻璃質感或 F1、F2 的粗黑科技感字體：材質打架。
- 模板 9（華麗揭示）配螢光色（P1、P7、P8）：金箔和煙火要深色底才顯得出來。
- 深色底配 Noto Serif TC 400 以下的細字重小字：H.264 壓縮後細橫線會糊掉，深底小字至少 500。
- 一支片頭用超過一組字體組、或三個以上強調色。
- 轉場手法「黑色形狀填滿」配淺色底色票時，改用主色填滿，不要硬用黑色，否則像斷訊。
