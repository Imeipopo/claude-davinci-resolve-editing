# 第 17 章　完整案例：照參考影片做照片卡點快剪

> 英文版：[docs/en/17-case-study.md](../en/17-case-study.md)

本章是作者用 Claude Code 做婚紗照卡點影片的實際流程（2026-10-08～10，共 19 支、每支多個版本）。屬於「作者實作經驗」：流程與數字都是真實專案的，但不是自動測試。音樂受版權限制不放進 repo；照片只放作者本人同意公開的 6 張單人照（`assets/photos/`，已縮小並清除 EXIF），示範程式為 [examples/17_photo_demo.py](../../examples/17_photo_demo.py)（6 條 PASS），效果圖散見 4.10、6.4、11.1、12.3、14.3。

## 17.1 整體流程

```
參考影片（IG / YouTube Reel）
  └→ 1. 逐格量測：切點、每個效果出現與結束的時間、畫面結構
音樂
  └→ 2. 拆分軌、抓 onset（第 16 章）→ cuts.json
照片
  └→ 3. 挑片：人臉偵測、銳利度、風格分組、排除不要的
       4. 照片轉 8 秒影片（2.6）；需要的效果預先算好（推近、去背、大字）
計畫
  └→ 5. plan.py：切點 × 照片 × 效果 → plan.json
剪輯
  └→ 6. build.py（ResolvePython）：建新時間軸 vN
       7. render.py：輸出
驗證
  └→ 8. 截格對照參考影片、量位置；傳預覽給人看（第 18 章）
修改
  └→ 9. 依回饋改 plan → v(N+1)，不覆蓋舊版
```

## 17.2 逐格量測參考影片

- 結論：先把參考影片的每個切點、效果的開始與結束時間量出來，寫成文字檔，再開始做。不要憑印象模仿。
- 做法：
  - `yt-dlp` 下載參考影片（公開影片，自己看與學習用）。
  - 用 ffmpeg 抽每一格，或用幀差找切點；每個效果（方塊拼接、直條、九宮格、閃白）各自記錄起訖時間。
  - 量完整段畫面，不要只靠「畫面差異事件」分群——作者曾因此漏掉一組只佔畫面一部分的直條，被使用者指出才補上。
- 作者實作經驗：照逐格量測重做的版本，使用者回饋明顯比憑印象做的好；憑印象用 shader 改了八版的另一個案子，被評為「越做越爛」。

## 17.3 挑照片

- 結論：用程式先篩，再讓人決定。
- 作者用過的條件：
  - 有臉（macOS Vision 人臉／人體偵測，43 張約 6 秒）。
  - 銳利度夠。
  - 同一組風格（例如中式、禮服、白紗、夕陽）平均分配。
  - 和已選照片的編號相差夠遠，避免連拍重複。
  - **排除使用者指定不要的照片**，並在每份計畫檔裡檢查一次。
- 裁切：九宮格、拼貼這類會切照片的版面，以人臉為中心算裁切範圍，所有臉都要入格；偵測不到的照片手動指定焦點。

## 17.4 效果：Resolve 原生還是預先算好

- 結論：能用 Resolve 原生做的（第 4～15 章）就用原生，使用者打開專案就能自己調；做不到的才預先算成片段放進去。
- 原生：切點、縮放位移裁切、轉場、Dynamic Zoom、字卡、調色、疊圖模式、Fusion 特效。
- 預先算好的例子（作者的做法）：人像去背（macOS Vision person segmentation）、3D 翻面、水彩暈開、2.5D 視差、逐字跳出的大字。
- 取捨：預先算好的片段在 Resolve 裡是「一整塊」，使用者改不了裡面。作者一開始大量用預先算好的片段，使用者才發現「原來沒有用到 DaVinci 的功能」，這是本教學第 4～15 章的起點。**做法改變時要主動告訴使用者。**

## 17.5 改版的節奏

- 結論：每次修改都開新時間軸（v2、v3……），並保留對應的 plan 檔。使用者講效果時用詞常很簡短，**先用一句話複述你的理解，確認了再做**。
- 作者實作經驗：
  - 使用者說「去背」，作者理解成「人物變白剪影」，做了一版白工；實際意思是「人物去背站在最前面、直條從人背後進來」。
  - 「白光之後要接大圖」：閃白之後要接滿版照片，不能接一個空的格子。
  - 歌詞位置以使用者的耳朵為準（16.8）。

## 17.6 預覽給人看

- 結論：輸出後傳給使用者看，影片用可以直接播放的方式傳（例如 Telegram 的 sendVideo，50 MB 上限，超過先壓縮）。
- 不要：螢幕錄影前沒確認畫面——作者曾在螢幕鎖定時錄影，錄到的只有桌布。

## 17.7 版權

- 結論：從參考影片抽出的音樂只能自己看。要公開發布（例如 IG），輸出時關掉音樂，上傳後從平台的音樂庫加。平台音樂庫的歌只授權在該平台內使用，不代表沒有版權。
